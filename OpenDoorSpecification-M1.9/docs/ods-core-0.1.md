# ODS Core 0.1 overview

ODS Core 0.1 is the smallest portable contract justified by the current corpus. It covers
identity, node, connection state, basic terminal I/O, and explicit lifecycle termination.
Line input, time remaining, host status, and generic host commands remain optional.

The machine-readable source of truth is `catalog/operations/core.json`. Historical mappings
are under `catalog/mappings/` and can be inspected with the CLI.
