# M4.7 Historical corpus expansion

M4.7 inventories and classifies four newly supplied archives and records five byte-identical redistributions.

## Findings

- **ACP 3.00** is a 34-entry C source release. Its payloads use `-lh1-`; M4.7 records the complete inventory but does not promote semantic API claims without readable source text.
- **AX 3.00** is a 116-entry C source release. The inventory identifies `paraport.c`, `bbs.h`, `bbs.protos`, and `aeputstr.c` as high-value follow-up evidence. Most payloads use `-lh1-`; only stored metadata files were directly readable.
- **mAGNUM cHAT 1.10** is a documented MaxsBBS chat door. Its guide confirms installation as menu function 34, caller-time freeze/resume, raw transfers, and use of the standard logoff command.
- **Multi-Quest 1.1** is a documented Maxs BBS 1.52+ questionnaire door supporting strings, hotkeys, multiple choice, and optional ANSI screens.

No new normative ODS operation or historical API mapping is introduced. The evidence boundary is intentional: inventory data and documentation are recorded, while source-level claims are deferred until `-lh1-` extraction is available.

## Duplicate redistributions

`MaxPro2 (1).lha`, `DayDreamBBS (1).lha`, `DayDreamBBSDev (1).lha`, `DayDreamBBSDoo (1).lha`, and `max_e (1).lha` are SHA-256-identical to their canonical copies and are not catalogued as new archives.
