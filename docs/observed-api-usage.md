# Observed historical API usage

The machine-readable source is `catalog/evidence/historical-door-corpus.json`. Counts are static-analysis observations used to rank confidence and prioritize adapters; they are not runtime telemetry and must not be interpreted as exact execution frequency.

The corpus provides independent practical evidence for terminal output, prompts, key input, user information, file display/check operations, BBS functions, access changes, time changes, disconnect handling, and the command 20 exit handshake.
