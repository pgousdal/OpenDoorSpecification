# Provenance records

This directory contains machine-readable claims conforming to `schemas/provenance-record.schema.json`.

M4.1 defines the model and validation rules. Claims are added incrementally only when their archive and entry references can be checked automatically.

## Populated records

M4.2 adds machine-readable primary-source records for DayDream and Paragon/MAXs. See `docs/provenance-population.md`.
