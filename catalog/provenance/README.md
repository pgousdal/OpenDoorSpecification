# Provenance records

This directory contains machine-readable claims conforming to `schemas/provenance-record.schema.json`.

M4.1 defines the model and validation rules. Claims are added only when their
archive and entry references can be checked automatically.

## Records and crosswalk evidence

The directory includes canonical provenance records introduced across the M4
milestones. Reviewed M6 crosswalk mappings additionally carry inline,
machine-validated evidence references in the census and generated crosswalk
records. See `docs/provenance-population.md` and
`docs/m62-evidence-provenance-validation.md`.
